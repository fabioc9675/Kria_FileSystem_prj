# Creacion de platform en Vitis

Para crear el platform hay que abrir la herramienta XSCT en vitis y correr el siguiente comando

```bash
source C:/GitHub/Kria_Arch_A_prj/Vitis/platform.tcl
```

## Procedimiento desde terminal Bash en Windows

```bash
export PATH="/d/Xilinx/Vitis/2022.2/bin/:$PATH"

cd /c/Kria_Arch_A_prj/Vitis/

xsct -nodisp platform.tcl
```
